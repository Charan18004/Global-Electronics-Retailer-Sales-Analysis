# Global Electronics Retail Sales Analysis & Interactive Dashboard

## 📊 Project Overview

An end-to-end **Global Electronics Retail Sales Analysis and Interactive Dashboard** developed using Microsoft Excel.

The project transforms raw multi-table retail data into a structured analytical solution using **Power Query, Power Pivot, DAX, PivotTables, PivotCharts, Slicers and KPI reporting**.

## 🛠️ Tools & Technologies

* Microsoft Excel
* Power Query
* Power Pivot
* DAX
* PivotTables & PivotCharts
* Slicers & Timeline
* Data Modeling
* Data Cleaning & Validation
* KPI & MIS Reporting

## 📂 Dataset

The project uses multiple interconnected datasets:

* Customers
* Sales
* Products
* Stores
* Exchange Rates

## 🔄 Project Workflow

**Raw Data → Data Understanding → Data Cleaning → Data Modeling → Analysis → Dashboard**

### 1. Data Understanding

* Identified table structure and grain
* Identified primary and lookup keys
* Reviewed relationships between datasets
* Performed initial data-quality checks

### 2. Data Cleaning & Transformation

Used **Power Query** to:

* Standardize data types
* Handle date-related data issues
* Validate keys
* Check missing values
* Check duplicates
* Validate numerical fields
* Transform data for analysis

### 3. Data Modeling

Built a relational model using **Power Pivot**, connecting:

**Sales → Customers**
**Sales → Products**
**Sales → Stores**
**Sales → Exchange Rates**

### 4. Analysis

Created DAX measures and KPIs including:

* Total Sales Amount
* Total Quantity
* Total Line Items
* Average Sales

### 5. Interactive Dashboard

The dashboard provides analysis of:

* Sales performance by country
* Order performance by country
* Sales performance over time
* Sales by category
* Sales by brand
* KPI performance

Interactive filters include:

* Gender
* Order Date / Year
* Category
* Country

## 📈 Key Business Insights

* **Total Sales:** 55.76M
* **Highest Sales Contributor:** United States — **42.62%**
* **Lowest Sales Contributor:** France — **2.21%**
* **Online Sales Contribution:** **20.45%**

The analysis demonstrates how raw transactional data can be transformed into meaningful business insights and management-level reporting.
